## 1. 개요 및 배경

2026 정보처리기사 실기 시험까지 약 25일 남은 시점에서, 수험생은 모바일 환경에서 출퇴근 및 자투리 시간을 활용하여 5문항/10문항 단위의 짧은 퀵 퀴즈 세션을 집중적으로 반복 학습합니다.
기존 출제 알고리즘에는 다음과 같은 구조적 한계가 존재했습니다.

1. **신규 문제(`NEW`)의 출현 기회 고갈**:
   기존 로직은 `dueTarget = Math.round(count * 0.5) (약 3문항)`과 `weakTarget = Math.round(count * 0.3) (약 2문항)`으로 슬롯 5개를 먼저 채워버렸기 때문에, 정작 수험생이 **한 번도 보지 못한 800여 개의 신규 문제**가 5문항 세션에 거의 등장하지 못하는 현상이 발생했습니다.
2. **최근 본 문제의 불필요한 즉시 반복(쿨다운 부재)**:
   방금 푼 문제가 바로 다음 5문항 세션에 다시 뽑히며 체감상 문제은행이 매우 좁게 느껴지는 피로감을 유발했습니다.
3. **"다시 풀기" 실행 시 무작위 셔플로 인한 순서 붕괴**:
   방금 푼 5문항 세션의 결과를 보고 틀린 문제를 복기하기 위해 "다시 풀기"를 눌렀을 때, Q1~Q5가 다시 무작위로 섞여 출제자의 사고 흐름과 복기 맥락이 단절되었습니다.

## 2. 5단계 계층형 출제 우선순위 알고리즘 구현

`src/repositories/questionRepository.ts`의 `getQuickQuizQuestions`를 전면 개편하여, 단기 모바일 학습에 최적화된 **5단계 우선순위 분배 + 쿨다운 배제 정책**을 적용했습니다.

### 2.1 계층 구조 (5-Tier Priority)

```
[ 전체 900문항 풀 ]
       │
       ▼ (1단계: 쿨다운 필터링)
[ 최근 1~2세션 출현 10문항 제외 가용 풀 ]
       │
       ├─▶ Tier 1. NEW (한 번도 풀지 않은 문제): 5문항 중 최소 3문항(60%) 최우선 할당
       ├─▶ Tier 2. WEAK (오답 누적 취약 문제): 1~2문항 보충 할당
       ├─▶ Tier 3. DUE (에빙하우스 망각곡선 복습 도래 문제): 남은 슬롯 우선 배정
       ├─▶ Tier 4. GENERAL (기타 일반 풀이 이력 문제, MASTERED 제외)
       └─▶ Tier 5. MASTERED (연속 3회 이상 정답 문항): 풀 고갈 시에만 최후순위 배정
```

### 2.2 세부 구현 내용

1. **NEW 문항 최소 60% 보장 (`targetNew = Math.min(count, Math.max(3, Math.ceil(count * 0.6)))`)**:
   - 5문항 세션 시 최소 3문항은 무조건 아직 풀지 않은 신규 문제가 선별되어 문제은행 전체 900문항의 탐험률이 극대화됩니다.
2. **최근 1~2세션(10문항) 쿨다운 윈도우 적용**:
   - `HomeScreen.tsx`에서 최근 2개 세션의 풀이 기록(`sessionAttempts.slice(-10)`)을 추출하여 `recentQuestionIds`로 전달합니다.
   - 선별 엔진은 이 10문항을 1차 선별 풀에서 완전히 배제하여 즉각적인 중복 출현을 원천 방지합니다.
3. **MASTERED 문항의 일반 5문항 출현 빈도 억제**:
   - 정답률이 100%에 가깝고 3회 이상 안정적으로 맞힌 문제는 일반 5문항 세션에 반복 노출되지 않도록 후순위 격리합니다.
4. **"다시 풀기" 순서 100% 보존 (`preserveOrder: true`)**:
   - `src/store/quizStore.ts`의 `startQuiz`에 `options?: { preserveOrder?: boolean }`을 지원하고, `App.tsx`의 `handleRetryQuiz`에서 `{ preserveOrder: true }`를 전달하여 방금 푼 동일 5문항이 Q1부터 Q5까지 원본 순서 그대로 재출제되도록 보정했습니다.
